# ふりーむ投稿後改良を加えたところ、及びこだわりポイント
## テキスト文字送りアニメーションバグ修正及びオープニング、エンディングのローカライズ対応

 ふりーむ投稿時に文字送りのアニメーションのバグとして一瞬改行前のテキストが表示されてから改行されてしまうというバグがあった。
 シナリオ部分のローカライズ対応をしていく中で原因を探ったところ、スペースキーで改行ができるとチーム内では判断していたが、実際のところは一瞬半角の文字データが入ったと見なされて表示されてから、正しい改行が始まってしまうことが分かった。スペースを入れずに対応することも考えたが、言語によっては対応できたとは言えない対応だと考えた。そこで、スペースを入れた場合はそのまま文字送りのアニメーションを行い、改行そのものは文章内では絶対に使わない改行コードを入れることで対応した。

## スクリプタブルオブジェクトで設定するアイテム、選択肢が変動するイベントシナリオのローカライズ化対応

ローカライズをしていく上でスクリプタブルオブジェクト内で直接編集する方法でもありだが、その場合、実際に商品として出すとなった際にローカライズを行う翻訳者、プランナーがUnityを触る必要が出てきてしまい、その分連携など余計な時間がかかってしまう。そこで、Unity外で編集できるようにするにはどうすればいいのか色々調べていく中でグーグルシートとの連携をプログラムを書かずに実現できるGoogle Sheets APIというものがあることが分かった。これとローカライゼーションアセットを組み合わせることで、Unity側で編集した内容はグーグルシーズン側に反映、追加することができ、グーグルシート側の編集結果はUnity側にすぐに反映することができた。また、スプレッドシート内の関数を利用することでグーグル翻訳を用いて自動翻訳対応を行うことができた。

## タイトル画面のオプション画面でボタンを押すことで日本語と英語を切り替えることのできる仕組みの実装

ローカライズ対応を行うのであれば、タイトル画面でどの言語で遊ぶのかが選べる仕組みが必要だと感じた。
