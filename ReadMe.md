 # こだわりポイント
## 汎用的なシーン遷移の仕組みの実装

これまでの経験でシーン遷移はどのシーンでも行い、参照できる必要があると感じ、シングルトンで管理、また、より汎用的なプログラムにするにはStringを渡してシーン遷移を行うのではなく、シーンオブジェクトを設定することで簡単にシーン遷移が行えるのではないかと感じ制作を行った。その結果、柔軟にシーン追加及びシーン遷移の対応を行うことができた。

## チュートリアル画像表示システム
ゲーム開始時や特定の操作を説明する「画像ベースのチュートリアル表示システム」をUnityで実装。スプライト画像を順番に表示し、プレイヤーに操作や世界観の導入を提供するための機能です。CanvasやImageはプレハブ化されており、ゲーム進行に合わせてオンデマンドで生成・破棄されます。
　Canvasおよびチュートリアル用Imageをプレハブ化し、必要時のみ動的に生成・破棄する設計。これにより、ゲーム内UIの最小化を実現しました。

## 上記のスクリプト、及び、別担当者のプログラムなどを継承することで最小限のプログラムでチュートリアル機能の実現
プレイヤー、敵の挙動、及びステータス関連のスクリプトは一部仕様を除き共通しているため継承を用いて簡略化、メインゲームに影響を及ぼさないように設計しました。
